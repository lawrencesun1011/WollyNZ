## 产品概述

调整 NZ 游学库网站顶部导航与中小学学校库页面的水平对齐与右上角入口。

## 核心功能

    - 顶部 Header 左侧 "NZ 游学库" Logo 向左移动，与下方内容区左边缘对齐
    - 移除右上角"中文 / EN"语言切换，改为"登录"虚拟占位入口（视觉样式，暂不可点击，后续开发）
    - 修复中小学学校库页面下方学校列表与地图卡片和上方筛选框左右边缘不对齐的问题

## 技术栈

    - Next.js + React + TypeScript
    - Tailwind CSS
    - Lucide React icons

## 实现方案

通过统一 Header 与页面内容区的最大宽度容器和水平内边距，解决 Header 与下方内容区、以及内容区内部模块之间的左右对齐问题。

### 关键修改点

    1. **SiteHeader（src/components/site-header.tsx）**

    - 将导航容器从 `max-w-7xl px-5` 调整为与学校页一致的外层 `px-6 lg:px-10` + 内层 `mx-auto max-w-[1400px]`。
    - 移除右侧"中文 / EN"静态标签。
    - 在右侧添加 `登录` 占位按钮，使用 `disabled` 和弱化视觉样式，表示后续开发。

    1. **SchoolsExplorer（src/components/schools/schools-explorer.tsx）**

    - 将 `<main>` 区域从 `mx-auto max-w-[1400px] ... px-6 lg:px-10` 改为外层 `px-6 lg:px-10` + 内层 `mx-auto max-w-[1400px] flex gap-5`。
    - 使下方学校列表+地图卡片的实际内容宽度与上方标题区、筛选区完全一致，左右边线对齐。

## 性能与可靠性

    - 仅涉及 CSS 容器类名调整，无新增依赖、无运行时逻辑变化。
    - 保持现有响应式断点（sm、md、lg、xl）与组件结构不变。
    - Header 保持 fixed 定位，原有 `pt-16` 顶部间距不受影响。
